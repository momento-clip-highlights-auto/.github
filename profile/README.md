## Clip Automation Overview

The application runs alongside a game, monitors events, and marks candidate moments for review. Selected clips can be trimmed and exported at a chosen quality. A library collects sessions for later editing.

Users review detected moments after a session, discard the false positives, and export keepers into an editor. Momento features that come up include the detection sensitivity, the review timeline, and the export presets.
